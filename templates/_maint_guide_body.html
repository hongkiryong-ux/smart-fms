① 정비의뢰자 현장 운영·점검 담당

정비관리 › 정비접수/승인 「＋ 정비의뢰」 또는 설비관리 › 설비 상세 「정비의뢰」

  • 건물 → 설비를 고르고 의뢰내용·우선순위(긴급/일반)·희망 예정일을 입력합니다.
  • 현장 사진을 첨부하면 자동으로 축소 저장됩니다(기본 1년 보관, 「영구 보관」 선택 가능).
  • 설비관리에서 의뢰할 때는 협력사 지정 필수 — 지정하면 위험등급·잠재위험·안전대책이 협력사 기본값으로 채워집니다.
  • 반려되면 상단 알림으로 사유가 오므로, 보완해 다시 의뢰합니다.
  • 진행 상황은 정비 상세의 「정비 진행 단계(의뢰→진행→완료)」로 확인합니다.

② 정비섹션 접수·업체 배정

정비관리 › 정비접수/승인(정비섹션)

  • 매일 16:00 이전까지 업체 지정·D-1 승인을 마칩니다.
  • 상단 카드(정비의뢰·진행·완료·반려·승인대기)를 눌러 처리할 건만 봅니다.
  • 행의 협력사를 지정한 뒤 「승인」 → 협력사 D-1 리스트로 전송됩니다. 여러 건은 체크 후 「선택 항목 일괄승인」(업체 미지정 건 제외).
  • 부적합한 의뢰는 「반려」에 사유 입력 → 의뢰자에게 알림. 「승인됨」을 누르면 D-1 승인 취소.
  • 진행상태·예정일·협력사를 고친 뒤 「저장」.
  • 「나의 협력사 설정」으로 담당 협력사 건만 보이게 할 수 있습니다.

③⑤ 협력사 작업 수행

정비관리 › 정비 List(D-1)/협력사 › 자사명

  • 매일 16:30 이전까지 예정일 지정·작업허가 요청을 마칩니다.
  • 탭: 정비접수(당일 배정) · 오늘작업 · 내일작업 · 정비 예정항목 · 정비완료항목.
  • 예정일 지정 → 「승인요청」(작업허가 요청). 체크 후 일괄 요청 가능, 예정일 없는 건은 요청 불가.
  • 「요청완료」= 시설섹션 확인 대기, 「승인완료/이름」= 작업허가 완료 → 이때부터 작업 착수.
  • 작업 후 조치내용 입력, 진행상태 「완료」 저장 → 완료요청(최종승인 대기). 상세에서 작업 전·후 사진 첨부, 잠재위험·안전대책 확인.
  • 완료요청이 반려되면 「진행」으로 돌아오니 사유 확인 후 보완해 다시 완료 처리합니다.
  • 배정 업체 변경·신규 의뢰 등록은 할 수 없습니다. 접수·전날 작업예정 메일이 자동 발송됩니다.

④⑤ 시설섹션 관리감독자 작업허가 · 직원 완료처리

정비관리 › 작업허가/승인(시설섹션)

  • 작업허가 승인은 시설섹션 관리감독자가 안전 확인 후 매일 18:00 이전까지 처리합니다.
  • 탭: 하루전 작업(내일 예정) · 당일 작업 · 정비 예정작업 · 전체. 협력사가 승인요청한 건만 표시됩니다.
  • 「승인」 → 위험등급·잠재위험·안전대책 확인·수정 후 승인하면 진행상태가 「진행」으로 바뀝니다. 체크 후 「선택 항목 일괄승인」 가능.
  • 「승인됨/이름」을 누르면 작업허가 취소.
  • 협력사별 안전대책 기본값을 저장해 두면 다음 승인 창에 미리 채워집니다.
  • 시설섹션 직원 완료처리: 협력사 대신 진행상태 「완료」 저장(또는 정비 상세 「정비완료 처리」) → 최종승인 없이 바로 정비완료·정비이력 등록.
  • 「내 건물 설정」으로 담당 건물 작업만 볼 수 있습니다.

⑥ 최종승인 정비섹션·시설섹션 공통

정비관리 › 정비완료 최종승인

  • 탭: 전체 · 승인대기 · 승인완료 · 반려. 「금일 완료요청」 카드로 오늘 요청 건 확인.
  • 협력사가 완료요청한 건의 조치내용·사진 확인 후 「승인」(또는 체크 후 일괄 최종승인) → 정비완료 처리, 설비 정비이력 자동 등록.
  • 미흡하면 「반려」에 사유 입력 → 「진행」으로 되돌아가 협력사가 재요청합니다.
  • 조치내용 칸을 직접 고쳐 「저장」할 수 있습니다.

⚙ 관리자 · 조회자

정비관리 대시보드 우측 상단 「설정」

  • 접수메일 발송 설정: 협력사별·통합 수신 주소, 발송 시각.
  • 작업 예정 항목 발송 설정: 매일 지정 시각에 다음날 확정 작업을 협력사별(자사 건만)·통합 주소로 발송. 「미리보기」·「테스트 발송」으로 확인.
  • 발신 계정: 공식 발신 메일 계정 등록.
  • 정비실적(변동비): 실적 자료 업로드·ZIP 일괄 다운로드.
  • 조회자는 모든 화면을 보기만 가능(저장·승인 버튼 없음). 메뉴 권한은 계정관리에서 부여.
